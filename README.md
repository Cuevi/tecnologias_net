## 📌 Descripción

Este repositorio contiene diferentes **ejercicios, pruebas y pequeños proyectos** desarrollados mientras aprendo y practico tecnologías del ecosistema **.NET**.

Los objetivos principales son:

- Practicar POO
- Uso de SOLID
- Practicar conceptos de programación tanto backend como frontend
- Experimentar con distintas tecnologías de .NET
- Mejorar la organización de proyectos
- Aplicar buenas prácticas de desarrollo

📍 Este repositorio irá creciendo con nuevos ejercicios y proyectos.

## ▶️ Cómo ejecutar los proyectos

1. Clonar el repositorio

```bash
git clone https://github.com/Cuevi/dotnet-practice.git
```

2. Entrar en el proyecto que quieras ejecutar

```bash
cd projects/api-todo
```

3. Ejecutar la aplicación

```bash
dotnet run
```
